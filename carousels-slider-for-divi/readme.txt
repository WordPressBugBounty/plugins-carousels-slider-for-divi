== Description ==

Divi Carousel Lite is a powerful carousel plugin built exclusively for Divi Theme and Divi Builder users. It extends the Divi Builder with beautiful, responsive carousel modules that help you showcase images, logos, testimonials, blog posts, products, team members, and other content without writing a single line of code.

Whether you're creating a business website, agency portfolio, online store, personal blog, or landing page, Divi Carousel Lite gives you complete control over your carousel layouts while keeping the familiar Divi Builder experience you already know.

Every module is designed to feel native to Divi, making it simple for beginners while providing advanced customization options for designers and developers.

= Minimum Requirements =

* WordPress 5.0 or higher

For the best experience, we recommend:

* Latest version of WordPress

* PHP 8.0 or higher
* HTTPS enabled
* WordPress Memory Limit: 128MB or higher

= Installation =

Installing Divi Carousel Lite is quick and easy.

1. Log in to your WordPress Dashboard.
2. Navigate to Plugins → Add New.
3. Search for "Divi Carousel Lite".
4. Click Install Now.
5. Activate the plugin.
6. Open any page with Divi Builder.
7. Click Add New Module.
8. Search for "Carousel".
9. Select your preferred carousel module.
10. Customize the settings and publish your page.

You can also install the plugin manually by uploading the plugin folder to:

/wp-content/plugins/

Then activate the plugin from the Plugins screen.

== Frequently Asked Questions ==

= Does this plugin require Divi? =

Yes. Divi Carousel Lite is designed exclusively for Divi Theme and Divi Builder. It will not work with other page builders.

= Does it support Divi 5? =

Yes. Divi Carousel Lite is compatible with both Divi 4 and Divi 5.

= Is Divi Carousel Lite free? =

Yes. The Lite version is completely free and available from the WordPress Plugin Repository.

= What is included in the Lite version? =

The Lite version includes responsive carousel modules with professional carousel controls, responsive settings, autoplay, navigation, pagination, touch support, and more.

= What additional features are available in Pro? =

Divi Carousel Pro includes 17+ premium modules, WooCommerce Carousel, Team Carousel, Testimonial Carousel, Blog Carousel, Google Reviews, Instagram Feed, Facebook Feed, Video Carousel, and over 50 professionally designed layouts.

= Will upgrading to Pro affect my existing layouts? =

No. Your existing Lite modules continue working after upgrading.

= Is the plugin mobile responsive? =

Yes. Every module is fully responsive and allows independent settings for desktop, tablet, and mobile devices.

= Does it support touch swipe? =

Yes. Visitors can swipe through carousels on touch devices.

= Can I disable autoplay? =

Yes. Autoplay can be enabled or disabled for every carousel.

= Can I customize navigation arrows? =

Yes. Navigation arrows can be enabled, disabled, and customized.

= Can I hide pagination dots? =

Yes. Pagination can be enabled or disabled from the module settings.

= Can I control the number of visible slides? =

Yes. Configure different numbers of visible items for desktop, tablet, and mobile.

= Does it support infinite looping? =

Yes. Loop mode is available for supported carousel modules.

= Is coding required? =

No. Everything is managed from the Divi Visual Builder.

= Does it work with WooCommerce? =

The Lite version works alongside WooCommerce. The dedicated WooCommerce Product Carousel module is available in Pro.

= Is the plugin lightweight? =

Yes. Divi Carousel Lite is optimized for performance and loads only the assets required for the carousel.

= Does it support RTL languages? =

Yes. RTL layouts are supported.

= Can I use multiple carousels on one page? =

Yes. There is no limit to the number of carousel modules you can add.
